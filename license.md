## 🐍 The Problem With Tutorial Hell

You have watched hundreds of hours of Python tutorials. You understand what a `for` loop is. You can write a function. But when someone asks you to build something from scratch, you freeze. This is called **Tutorial Hell**, and it is the number one reason why aspiring developers give up.

**100 Days Python Projects** is the antidote. This repository is a curated collection of 100 progressively challenging Python projects, designed to take you from absolute beginner to confident developer. It is not a collection of toy scripts; each project is a fully functional, useful application that solves a real problem.

From a simple command-line calculator on Day 1 to a full-stack web application with a database on Day 100, this repository provides the structured practice you need. Each day includes the complete source code, a detailed explanation of the concepts used, and a series of challenges to extend the project further.

---

## 🗺️ The Learning Roadmap

We have broken down the 100 days into four distinct phases. Each phase builds on the previous one, introducing new concepts and libraries.

### Phase 1: The Foundations (Days 1-25)
You will master the basics: variables, loops, conditions, and functions. You will build CLI tools like a password generator, a unit converter, and a text-based adventure game. By the end of this phase, you will be comfortable writing Python scripts without looking at a tutorial.

### Phase 2: Automation & Scripting (Days 26-50)
This is where Python becomes a superpower. You will learn to interact with the operating system, read and write files, and scrape websites. You will build a bulk file renamer, a PDF merger, an automated email sender, and a web scraper that tracks prices on e-commerce sites.

### Phase 3: Data & APIs (Days 51-75)
You will learn to work with data. This phase covers JSON, CSV, and SQL databases. You will learn how to consume REST APIs. You will build a weather app, a currency converter using live exchange rates, and a personal expense tracker with a SQLite backend.

### Phase 4: Web & GUI Development (Days 76-100)
The final phase. You will build graphical user interfaces with Tkinter and web applications with Flask. You will build a calculator app, a notes app with cloud sync, and finally, a full-stack blog with user authentication, CRUD operations, and a beautiful Bootstrap frontend.

## 🧠 Under The Hood: The Project Architecture

Every project in this repository follows a consistent structure. This is intentional. By seeing the same structure repeated 100 times, you subconsciously learn best practices.

Each project folder contains:
- `main.py`: The entry point of the application.
- `requirements.txt`: The dependencies you need to install.
- `README.md`: A detailed explanation of the project, including the learning objectives and the challenges.
- `assets/`: Any images, fonts, or data files used by the project.

The code is heavily commented. We don't just write the code; we explain *why* we wrote it that way. For example, in the web scraper project, we explain why we use `BeautifulSoup` over regular expressions, and how to handle rate limiting to avoid getting blocked by the website.

## 🤝 Community & Contributing

The best way to learn is to build. If you have completed a project and added your own twist, found a bug in one of the scripts, or want to add a new project to the list, we welcome your contributions!

1. **Fork** the repository.
2. **Create** your feature branch (`git checkout -b feature/new-project`).
3. **Commit** your changes (`git commit -m 'Add new project'`).
4. **Push** to the branch (`git push origin feature/new-project`).
5. **Open** a Pull Request.

Please read our `CONTRIBUTING.md` for detailed coding standards and testing requirements. We also have an active Discord server where you can share your progress, ask for help when you get stuck, and find study partners to do the challenge with.
